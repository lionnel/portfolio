# Porfolio

Manage a portfolio, grabbing quotation from Yahoo finance.

## Pre-requisits

nodejs 22.18 + npm 10.9

## Launch

1rst time or if changed, perform `npm install` to get dependencies.

Launch `node server.js` then browse <http://localhost:3000>

Data are stored in `data` directory. May backup it frequently.
